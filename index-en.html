E-commerce Platform – Java & Spring Boot

Fullstack-oriented e-commerce application with focus on backend development, architecture and data-driven design. The project started as a console application and has since been further developed with a web layer.

Tech: Java 21, Spring Boot, Spring Data JPA, Spring MVC, Thymeleaf, PostgreSQL

The project was originally developed as a school assignment with focus on database design, business logic and handling of larger data volumes. The application has since been further developed individually as a portfolio project in preparation for LIA.

The application is built around a clear domain model with products, customers, shopping cart, orders, payments, inventory and categories. Business logic is handled in a separate service layer with transactions.

A web layer has been added with Spring MVC and Thymeleaf. Functionality includes product lists with pagination, customer management, shopping cart with mini-cart in navbar, checkout flow and order history.

The system uses database-based role management (RBAC). Access is controlled in two layers: UI level (show/hide features) and backend level where admin endpoints are protected against direct URL access.

For reporting, separate DTO classes are used to avoid direct exposure of domain entities. Available reports include best-selling products, low inventory and revenue per time period.

To simulate realistic scenarios, there is support for CSV import of products, customers and orders as well as a data generator for larger data volumes.

Todo App – PWA with Vite & CI/CD

Complete Todo application built as a Progressive Web App with offline support, test-driven development and automated deploy via GitHub Actions.

Tech: JavaScript, Vite, Vitest, Service Workers, Web App Manifest, GitHub Actions, GitHub Pages

The app is built with an API adapter that selects between an HTTP implementation (json-server during development) and a localStorage-based mock implementation for deploy – no backend required on GitHub Pages.

Testing with Vitest covers multiple levels: unit tests for todo logic, API tests with mocked fetch including error scenarios (500, network errors), DOM tests with jsdom and integration tests for user flows.

CI/CD pipeline with GitHub Actions runs lint, tests and build on every PR. Branch protection requires green checks before merge. CD workflow builds and deploys automatically to GitHub Pages.

PWA functionality includes service worker with caching strategies, offline banner, robust error handling with retries for failed syncs and code splitting with dynamic imports for statistics and settings views.

Collection App – PWA Group Project

PWA application built in a team using data from an external API. Focus on offline functionality, accessibility, responsive design and shared Git workflow with CI/CD.

Tech: HTML, CSS, JavaScript, Service Workers, Web App Manifest, GitHub Actions, GitHub Pages

The app fetches data from an external API and presents it in a list view with search/filtering and detail pages. Users can save favorites that work offline via local storage.

Service worker caches app shell and API responses with clear caching strategies. Offline mode displays cached data with feedback to the user about limited functionality.

Accessibility has been central: semantic HTML, keyboard navigation, sufficient contrast and ARIA where needed. Tested with axe targeting 90+ in Accessibility.

Collaboration with branch protection, required checks and shared planning. CI/CD pipeline deploys automatically to GitHub Pages.

BankTransfer – Transactions & Testing

Java application for bank transfers with focus on transaction handling, rollback and error handling. The project is test-driven and verifies that database transactions work correctly for both successful and failed transfers.

Logging occurs in a separate transaction (REQUIRES_NEW) to ensure that failed transfers are always logged, even during rollback. Tests run against a local PostgreSQL database.

Tech: Java, Spring Boot, Spring Data JPA, PostgreSQL, JUnit
