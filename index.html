Projekt byggda under utbildning och egen utveckling

E‑handelsplattform – Java & Spring Boot

Fullstack‑orienterad e‑handelsapplikation med fokus på backendutveckling, arkitektur och datadriven design. Projektet påbörjades som en konsolapplikation och har därefter vidareutvecklats med ett webblager.

Teknik: Java 21, Spring Boot, Spring Data JPA, Spring MVC, Thymeleaf, PostgreSQL

Projektet utvecklades ursprungligen som en skoluppgift med fokus på databasdesign, affärslogik och hantering av större datamängder. Därefter har applikationen vidareutvecklats individuellt som portföljprojekt inför LIA.

Applikationen är uppbyggd kring en tydlig domänmodell med produkter, kunder, kundvagn, ordrar, betalningar, lager och kategorier. Affärslogik hanteras i ett separat service‑lager med transaktioner.

Ett webblager har lagts till med Spring MVC och Thymeleaf. Funktionalitet inkluderar produktlistor med pagination, kundhantering, kundvagn med mini‑cart i navbar, checkout‑flöde samt orderhistorik.

Systemet använder databaserad rollhantering (RBAC). Åtkomst styrs i två lager: UI‑nivå (visa/dölj funktioner) och backend‑nivå där admin‑endpoints skyddas mot direkt URL‑åtkomst.

För rapportering används separata DTO‑klasser för att undvika direkt exponering av domänentiteter. Tillgängliga rapporter inkluderar bästsäljande produkter, lågt lager och omsättning per tidsperiod.

För att simulera realistiska scenarier finns stöd för CSV‑import av produkter, kunder och ordrar samt en data‑generator för större datamängder.

Todo‑app – PWA med Vite & CI/CD

Fullständig Todo‑applikation byggd som Progressive Web App med offline‑stöd, testdriven utveckling och automatiserad deploy via GitHub Actions.

Teknik: JavaScript, Vite, Vitest, Service Workers, Web App Manifest, GitHub Actions, GitHub Pages

Appen är uppbyggd med en API‑adapter som väljer mellan en HTTP‑implementation (json‑server under utveckling) och en localStorage‑baserad mock‑implementation vid deploy – ingen backend krävs på GitHub Pages.

Testning med Vitest täcker flera nivåer: unit tests för todo‑logik, API‑tester med mockad fetch inklusive felscenarier (500, nätverksfel), DOM‑tester med jsdom samt integrationstester för användarflöden.

CI/CD‑pipeline med GitHub Actions kör lint, tester och build på varje PR. Branch protection kräver gröna checks innan merge. CD‑workflow bygger och deployar automatiskt till GitHub Pages.

PWA‑funktionalitet inkluderar service worker med cache‑strategier, offline‑banner, robust felhantering med retries för misslyckade synkningar samt code splitting med dynamic imports för statistik‑ och inställningsvyer.

Samlingsapp – PWA Grupprojekt

PWA‑applikation byggd i grupp med data från externt API. Fokus på offline‑funktionalitet, tillgänglighet, responsiv design och gemensamt Git‑flöde med CI/CD.

Teknik: HTML, CSS, JavaScript, Service Workers, Web App Manifest, GitHub Actions, GitHub Pages

Appen hämtar data från ett externt API och presenterar det i en listvy med sök/filtrering och detaljsidor. Användaren kan spara favoriter som fungerar även offline via lokal lagring.

Service worker cachar app shell och API‑svar med tydliga cache‑strategier. Offline‑läge visar cachad data med feedback till användaren om begränsad funktionalitet.

Tillgänglighet har varit centralt: semantisk HTML, tangentbordsnavigering, tillräcklig kontrast och ARIA där det behövs. Testat med axe mot 90+ i Accessibility.

Samarbete med branch protection, required checks och gemensam planering. CI/CD‑pipeline deployar automatiskt till GitHub Pages.

GitHub

BankTransfer – Transaktioner & Testning

Java-applikation för banköverföringar med fokus på transaktionshantering, rollback och felhantering. Projektet är testdrivet och verifierar att databastransaktioner fungerar korrekt vid både lyckade och misslyckade överföringar.

Loggning sker i en separat transaktion (REQUIRES_NEW) för att säkerställa att misslyckade överföringar alltid loggas, även vid rollback. Testerna körs mot en lokal PostgreSQL-databas.

Teknik: Java, Spring Boot, Spring Data JPA, PostgreSQL, JUnit
